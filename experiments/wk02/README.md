# W02 시작점
[수업 전 15~20분 예습 문서](../../docs/W02_오늘_수업_예습.md)를 먼저 읽고, 아래 실습으로 넘어간다.

#2 → #22 → #23 순서. 이번 주 필수 자료는 고전 AI 수업 슬라이드다.
밑딥 1장의 Python/NumPy와 파이토치 첫걸음의 텐서 기초는 문법이 막힐 때만 참고한다.
정확한 페이지는 교재 판본/목차를 확인한 뒤 적는다.

1. 5×5 미로와 이동 비용 1을 고정하고 DFS/BFS/A* 방문 순서를 손으로 적는다.
2. search.py에 frontier 선택 → 목표 검사 → 이웃 방문 → 비용 갱신 의사코드를 쓴다.
3. game_search.py에 말단 평가 → MAX/MIN 재귀 → alpha/beta 갱신 의사코드를 쓴다.
4. rule_inference.py에 사실 집합/규칙 집합/목표와 중복·순환 방문 처리 방법을 쓴다.
5. 핵심 함수를 직접 구현하고 tests/에 동작 검증을 추가한다.
6. reports/REPORT_wk02.md의 실제 측정 표와 회상 답변을 채운다.

A*는 일관적 휴리스틱을 쓰거나 더 싼 경로 발견 시 재개방 처리를 해야 한다.
가중치 증가의 이득은 실험 결과로 판단한다. DFS/BFS와 A*의 방문·비용 갱신 규칙을 무조건 동일시하지 않는다.
