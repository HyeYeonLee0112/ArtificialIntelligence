## 두 교재를 쓰는 방식

밑딥은 《밑바닥부터 시작하는 딥러닝》 1권 기준이다. 기존 계획에서 확인한 범위는 W03 2~3장, W04 4~5장과 6.1이다. CNN 주차에는 convolution·pooling 관련 절을 찾아 읽는다. RNN/생성모델을 1권 내용으로 가정하지 않는다.

《파이토치 첫걸음》은 W01~02 텐서/기초 문법, W03~04 신경망·최적화, W05~09 CNN·학습, W12 RNN, W13 오토인코더, W14 GAN의 해당 절을 필요할 때 읽는다. 현재 실제 판본·목차와 교수 노트북 파일은 확인되지 않아 정확한 페이지·장 번호를 만들지 않는다. 탐지·분할은 강의자료를 우선한다.

이번 주 W02는 고전 AI 슬라이드가 주자료다. 두 교재 전체 장을 추가 과제로 읽지 않고 Python/NumPy·텐서 문법이 막힐 때만 보충한다.

## 매주 3시간 운영

화 60분 직관·손계산 → 수업 후 90분 교수 노트북 기준 실험과 조건 하나 변경 → 금 30분 그래프·오류 분석·회상 3개. W02는 탐색→게임→추론을 작은 예제로 나눠 진행하고 남은 구현은 이슈에 그대로 표시한다.

교수 노트북을 받으면 파일명·자료 버전·변경 셀을 보고서에 적는다. 계획만 만든 상태를 실험 완료로 체크하지 않는다. 시험 문제 형식은 실라버스에 명시되지 않았으므로 개념과 계산을 함께 준비한다.
