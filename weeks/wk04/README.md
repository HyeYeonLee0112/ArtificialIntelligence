# W04 손실·역전파·최적화
상태: PDF 대기 · 연결 이슈: #4
## 학습 목표
손실이 무엇을 나타내는지, 기울기가 가중치를 어느 방향으로 바꾸는지 손계산과 학습 곡선으로 연결한다.
## 강의계획서 기준 범위
loss function, gradient descent, backpropagation, SGD/Adam, learning rate, train/validation split, 학습 곡선 해석.
## PDF가 오면 이 폴더에서 확정할 것
- 수업에서 실제로 강조한 개념과 손계산 예시
- 직접 구현할 주제 파일과 함수 범위
- 구현 결과와 기대 결과를 비교할 검사 조건
- 수업 노트북, 교재의 필요한 절, 보고서 질문
기본 골격만 준비한 상태다. PDF 확인 전에는 구현 코드와 테스트 정답을 만들지 않는다.
